# タブアイコンの生成記録

- 作成方法: 組み込みの image_gen ツール
- 使用画像: `public/lottery-favicon.png`
- 用途: ブラウザーのタブに表示するfavicon
- デザイン: 青い背景、数字7の抽選ボール、金色のきらめき

## 生成プロンプト

```text
Use case: logo-brand
Asset type: square raster favicon for a Japanese lottery prediction website titled 宝くじ予想.
Primary request: Create one polished, extremely simple icon evoking lottery number predictions: a large white lottery ball carrying one bold dark blue numeral "7", with a small warm gold four-point sparkle suggesting a prediction. A blue rounded-square tile fills most of the square canvas; the ball is the dominant central shape. Match a clean modern blue-and-white website, with very strong contrast and a bold silhouette that remains legible at 16px and 32px.
Style: crisp flat graphic illustration, minimal details, clean edges, only subtle shading if needed. Square image, tightly framed with minimal exterior padding, genuinely transparent outside the rounded tile. No scene, no mockup, no surrounding objects, no border text, no Japanese lettering, no watermark. Only text is the numeral "7". Produce the single finished icon.
```
